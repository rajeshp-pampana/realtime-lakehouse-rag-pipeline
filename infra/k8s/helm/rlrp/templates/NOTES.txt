Wait for both Deployments to become available:
  kubectl -n {{ .Release.Namespace }} rollout status deploy/{{ .Release.Name }}-api
  kubectl -n {{ .Release.Namespace }} rollout status deploy/{{ .Release.Name }}-ui

With the kind cluster from infra/k8s/kind-cluster.yaml, the NodePorts are
mapped to the host:
  API   http://localhost:{{ .Values.api.service.nodePort | default 30800 }}  -> /docs, /health
  UI    http://localhost:{{ .Values.ui.service.nodePort | default 30851 }}

Inside the cluster the UI reaches the API at:
  http://{{ .Release.Name }}-api:{{ .Values.api.service.port }}
